# Demo Instructions

This demo shows the difference between a **broken** and **fixed** implementation of  
WSG 3.8: Defer the loading of non-critical resources.

## Run locally

1. Install http-server:
   ```bash
   npm install -g http-server

2. Run the broken version
    ```bash
    cd demo/broken
    http-server . -p 8000

    Open: http://localhost:8000

3. Run the fixed version

    cd demo/fixed
    http-server . -p 8001

    Open. http://localhost:8001
